# SchoolGr

Το SchoolGr είναι ένα πληροφοριακό σύστημα σχολικής διαχείρισης σε PHP και
MariaDB. Περιλαμβάνει περιβάλλοντα για διαχειριστές, εκπαιδευτικούς, μαθητές,
γονείς και οδηγούς σχολικών λεωφορείων.

## Παραγωγικό περιβάλλον

- Δημόσια διεύθυνση:
  [https://schoolmedia.34-116-171-152.sslip.io](https://schoolmedia.34-116-171-152.sslip.io)
- Google Cloud project: `school-gr-502820`
- Compute Engine VM: `schoolmedia-web`
- Περιοχή: `europe-central2-a`
- Στατική IP: `34.116.171.152`
- Λειτουργικό σύστημα: Ubuntu 24.04 LTS
- Web server: Apache
- PHP: 8.3
- Βάση δεδομένων: MariaDB

Η σύνδεση HTTP ανακατευθύνεται υποχρεωτικά σε HTTPS. Το πιστοποιητικό
Let's Encrypt ανανεώνεται αυτόματα μέσω Certbot.

## Δομή αποθετηρίου

- `app/`: πηγαίος κώδικας της εφαρμογής.
- `deployment/`: επαναλήψιμα scripts εγκατάστασης, SSL και ελέγχων.
- `docs/DEPLOYMENT.md`: αναλυτικές οδηγίες λειτουργίας και ανάπτυξης.
- `docs/SESSION_LOG.md`: ιστορικό σημαντικών εργασιών ανά συνεδρία.
- `AGENTS.md`: κανόνες για τις επόμενες συνεδρίες Codex.

## Ασφάλεια δεδομένων

Δεν αποθηκεύονται στο Git:

- πραγματικά αντίγραφα της βάσης δεδομένων,
- κωδικοί πρόσβασης ή αρχεία περιβάλλοντος,
- αρχεία μαθητών, γονέων ή ιατρικά έγγραφα,
- αρχεία μεταφόρτωσης και αντίγραφα ασφαλείας,
- πακέτα ZIP ή έτοιμα αρχεία ανάπτυξης.

Η εφαρμογή διαβάζει τα στοιχεία σύνδεσης της βάσης από μεταβλητές
περιβάλλοντος `SCHOOLMEDIA_DB_*`.

## Τοπικός έλεγχος

Για έλεγχο σύνταξης σε περιβάλλον με εγκατεστημένο PHP:

```bash
find app -name '*.php' -exec php -l {} \;
```

Οι οδηγίες παραγωγικής εγκατάστασης βρίσκονται στο
[docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).
